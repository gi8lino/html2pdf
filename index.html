html2pdf

A small HTTP service that renders self-contained UTF-8 HTML to PDF with WeasyPrint.

{{VERSION}} GitHub

API

Method Path Purpose
GET / This page
GET /healthz Health check
POST /render Render HTML and return application/pdf

Render a document

Send a UTF-8 HTML document as the request body using Content-Type: text/html. 

curl --fail-with-body \
  -H 'Content-Type: text/html; charset=utf-8' \
  --data-binary @document.html \
  http://localhost:8080/render \
  -o document.pdf

Authentication

Bearer authentication for /render is optional. When HTML2PDF__TOKEN is configured, include it in the Authorization header. 

curl --fail-with-body \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: text/html; charset=utf-8' \
  --data-binary @document.html \
  http://localhost:8080/render \
  -o document.pdf

Configuration

Setting Effective value
HTML2PDF__TOKEN {{AUTH_STATUS}}
HTML2PDF__LISTEN_ADDRESS {{LISTEN_ADDRESS}}
HTML2PDF__WORKERS {{WORKERS}}
HTML2PDF__TIMEOUT {{TIMEOUT}}s
HTML2PDF__MAX_HTML_BYTES {{MAX_HTML_SIZE}}
HTML2PDF__MAX_PDF_BYTES {{MAX_PDF_SIZE}}

The listen address is inside the container. Docker port mappings control the host address and port used to reach the service. If you change the listening port, update the container port in the mapping to match.

Asset policy

Documents must be self-contained. Images, fonts, and other resources must be embedded using data: URLs.

HTTP(S) resources, local files, and other external assets are intentionally rejected. This prevents submitted documents from using the renderer for network or local file access.
