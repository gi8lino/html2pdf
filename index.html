html2pdf

A small HTTP service that renders self-contained UTF-8 HTML to PDF with WeasyPrint.

API

Method Path Purpose
GET / This page
GET /healthz Health check
POST /render Render HTML and return application/pdf

Render a document

curl --fail-with-body \
  -H 'Content-Type: text/html; charset=utf-8' \
  --data-binary @document.html \
  http://localhost:8080/render \
  -o document.pdf

If HTML2PDF_TOKEN is configured, also send a bearer token: 

curl --fail-with-body \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: text/html; charset=utf-8' \
  --data-binary @document.html \
  http://localhost:8080/render \
  -o document.pdf

Asset policy

Documents must be self-contained. Images, fonts, and other referenced resources must use data: URLs. Network and file-system assets are intentionally rejected.

Maximum HTML request size: 32 MiB. Maximum generated PDF size: 64 MiB.
