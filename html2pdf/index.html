html2pdf

A small HTTP service that renders self-contained UTF-8 HTML to PDF with WeasyPrint.

API

Method Path Purpose
GET / This page
GET /healthz Health check
POST /render Render HTML and return application/pdf

Render a document

Send a UTF-8 HTML document as the request body using Content-Type: text/html. 

curl --fail-with-body \
  -H 'Content-Type: text/html; charset=utf-8' \
  --data-binary @document.html \
  http://localhost:8080/render \
  -o document.pdf

Authentication

Bearer authentication for /render is optional. When HTML2PDF__TOKEN is configured, include it in the Authorization header. 

curl --fail-with-body \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: text/html; charset=utf-8' \
  --data-binary @document.html \
  http://localhost:8080/render \
  -o document.pdf

Asset policy

Documents must be self-contained. Embed images, fonts, and other assets using data: URLs.

External assets, including HTTP(S) URLs and local files, are rejected to prevent network and filesystem access.
